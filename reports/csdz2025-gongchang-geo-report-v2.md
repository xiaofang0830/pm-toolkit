## 立刻做的三件事

### P0：补齐“发现与归属”基础信号

问题：商铺核心页未观察到 canonical 和 JSON-LD，平台 sitemap 路径返回 404 型 HTML，robots.txt 本轮因客户端拦截无法判断。  
证据：首页、供应产品页、公司介绍页、联系方式页 canonical 为空；抽样页面 JSON-LD 数量为 0；`qiye.gongchang.com/sitemap.xml` 返回 404 页面。  
影响：破坏“发现 -> 候选 -> 引用”的前两环，AI 即使读到内容，也不容易确认官方来源和页面归属。  
动作：平台侧修复或提供有效 sitemap/robots；商铺页能改模板时补 canonical、Organization/LocalBusiness/BreadcrumbList；不能改模板时至少在正文增加“官方商铺事实卡”和清晰内链。  
负责人：平台技术/商铺运营/SEO。  
成本：中。  
验收：无登录访问 sitemap 返回 XML；核心页有唯一 canonical；结构化数据字段可从页面可见正文回溯。

### P1：把首页改成“安防电子采购答案层”

问题：首页有公司类型、经营模式、主营、地址、产品推荐和公司介绍，但还没有把采购者问题整理成答案模块。  
证据：首页可见“安防设备、电子产品”、注册年份 2019、经营模式贸易商/服务商、地址、推荐产品和最新供应；公司介绍页有经营范围和主营行业。  
影响：AI 可以抽到零散事实，但难稳定回答“新疆辰顺主要供什么、适合什么场景、询价要准备什么、如何联系”。  
动作：新增公司事实卡、产品类别事实表、品牌/型号索引、应用场景表、询价资料清单和 8-12 个采购 FAQ。  
负责人：商铺运营/销售负责人/产品负责人。  
成本：低到中。  
验收：首页单页可回答公司是谁、卖什么、覆盖哪些品牌/品类、适合哪些场景、如何询价、信息来自哪里。

### P1：修复分类页和产品事实字段

问题：供应产品总列表可读，但“东疆摄像头”分类页抽样没有产品；详情页存在供货量或发货期限为空、产品说明来源混杂的问题。  
证据：供应产品页显示 9 页产品，抽样分类页正文只有栏目和免责声明；摄像机详情页供货总量为空、发货期限天数为空；主板详情页正文大段描述“深圳力锐斯电子有限公司”。  
影响：破坏“主内容抽取 -> 证据质量”的链路，AI 可能无法按分类检索，也可能把供应商、品牌商、产品说明混在一起。  
动作：重建分类绑定；详情页统一字段：品牌、型号、类别、价格、起订量、供货量、交期、更新时间、适用场景、来源/价格边界；清理与供应商实体不一致的说明。  
负责人：产品运营/销售工程师。  
成本：低到中。  
验收：分类页可见对应产品；抽样 10 个详情页字段完整；不出现无法解释的第三方公司主体混淆。

## 5. 技术实现建议

### 模板与正文顺序

先让正文可信，再补机器标记。首页建议在“公司介绍”和“最新供应”之前增加一块概览：

```html
<section id="company-facts">
  <h2>新疆辰顺电子科技有限责任公司概览</h2>
  <dl>
    <dt>经营模式</dt><dd>贸易商、服务商</dd>
    <dt>主营产品</dt><dd>安防设备、电子产品</dd>
    <dt>服务内容</dt><dd>网络系统集成、软件开发、安防工程施工、设备安装维修</dd>
    <dt>所在地</dt><dd>新疆乌鲁木齐市</dd>
  </dl>
</section>
```

### Schema 顺序

若平台允许添加 JSON-LD，优先补 Organization、LocalBusiness、BreadcrumbList；产品详情页再补 Product。不要把未在可见页面出现的授权、库存、交期或资质写进 schema。

```json
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "新疆辰顺电子科技有限责任公司",
  "url": "https://qiye.gongchang.com/csdz2025/",
  "telephone": "0991-3737306",
  "address": {
    "@type": "PostalAddress",
    "addressRegion": "新疆",
    "addressLocality": "乌鲁木齐市",
    "streetAddress": "新疆乌鲁木齐经济技术开发区（头屯河区）玄武湖路666号宝能城1-03栋1单元3307号"
  }
}
```

### 产品详情字段

详情页最小字段应统一为：产品名称、品牌、型号、类别、单价、起订量、供货量、发货期限、最后更新、适用场景、询价入口、信息边界。摄像机、主板、硬盘录像机抽样页已有部分字段，但供货量/发货期限存在空值，需要运营补齐。

### Canonical 与归属

商铺核心页当前未观察到 canonical；抽样产品详情页 canonical 指向 `chanpin.gongchang.com/show/...`。如果这是平台统一策略，商铺页需要在正文里加强“由新疆辰顺电子科技有限责任公司发布/供应”的实体归属；如果可配置，应避免同一商品在商铺域和商品域之间互相削弱。

### 第 6-7 天
