1. 结论与优先级

本版报告沿用中正锅炉 V2 的版式和信息组织方式，用风险等级和行动优先级替代复杂评分。核心判断来自 2026-08-18 对世界工厂网商铺首页、供应产品页、产品详情页、公司介绍页、联系方式页和官网补充观察。

高风险 供应产品列表抽取异常

供应产品页标题可见，但浏览器抽样正文为空；产品集合页可能无法作为检索候选和答案素材入口。

高风险 发现入口不稳定

sitemap.xml 返回 404 型 HTML；robots.txt 本轮被浏览器客户端拦截，需平台或服务器侧复核。

中风险 结构化信号缺失

首页、介绍、联系方式页未观察到 canonical；抽样页面均未观察到 JSON-LD。

中风险 答案素材未聚合

已有公司介绍、主营、产品分类、推荐产品和联系方式，但缺统一采购答案层。

立刻做的三件事

P0

确认供应产品列表是否可被抓取和抽取

供应产品页 https://qiye.gongchang.com/shho/sell/ 在浏览器抽样中页面标题为“供应产品”，但正文长度为 0。先联系世界工厂网平台或模板管理员复测 PC、移动、无登录、无 Cookie 状态；若平台短期不能修复，就在首页和公司介绍页增加“主推产品清单”和详情内链作为兜底入口。

P1

把首页改成“采购答案层”

首页已有主营、注册年份、经营模式、地址、认证、推荐产品等事实，但没有组织成“公司是谁、卖什么、适合哪些行业、怎么询价、证据来自哪里”的答案结构。建议新增公司事实卡、产品类别事实表、代理品牌/授权新闻索引、询价资料清单和 8-12 个采购 FAQ。

P1

统一商铺与企业官网的官方入口表达

联系方式页展示官网 www.shhangou.com，浏览器抽样可打开为 HTTPS；但官网 canonical 指向 /en/。需要明确商铺负责平台内采购入口，官网负责企业背书，并让企业名称、电话、地址、主营和官方入口跨页面保持一致。

5. 技术实现建议

P0

产品列表与内链兜底

优先修复 /sell/ 的无登录可读性。若平台模板短期不可控，在首页、公司介绍页和联系方式页补“主推产品清单”，每个产品指向可读详情页，避免产品事实只散落在不可发现页面中。

P0

sitemap 与 robots 复核

sitemap.xml 应返回 XML，包含商铺首页、供应产品列表、产品详情页、公司介绍页和联系方式页；robots.txt 应明确核心页面是否允许抓取，并声明可用 sitemap 地址。

P1

canonical 与官方入口一致性

商铺首页、介绍页、联系方式页当前未观察到 canonical；抽样产品详情页 canonical 指向 chanpin.gongchang.com 商品页。需要确认平台 canonical 策略，并让商铺与官网的官方入口表达一致。

P1

正文先行，再补 schema

能改模板时优先补 Organization、LocalBusiness、BreadcrumbList；产品详情页再补 Product。不要把未在页面可见正文出现的授权、价格、库存和资质写进 schema。

奥卡姆剃刀原则下，不建议先做复杂打分系统或大规模内容扩写。先把“列表页可读、首页可答、官网关系清楚、来源可回溯”这四件事做扎实，边际收益最高。

  "@context": "https://schema.org",
  "@type": "Organization",

  "url": "https://qiye.gongchang.com/shho/",
  "telephone": "021-51085161",
  "address": {
    "@type": "PostalAddress",
    "addressLocality": "上海",
    "streetAddress": "中江路388弄国盛中心1号楼905室"
  }
}
